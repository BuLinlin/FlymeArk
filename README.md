# FlymeArk — 第三方 App 接入 Flyme 实况通知 LSPosed 模块

> 为第三方应用适配 Flyme 原生实况通知胶囊。

📥 下载：[Releases](https://github.com/BuLinlin/FlymeArk/releases)（`FlymeArk-vX.Y.Z.apk`）

## ✅ 消息实况｜微信 / QQ / TIM

- 状态栏胶囊展示真实会话名、消息计数与时间，长文本自动省略
- 点击胶囊就地展开，最多展示 3 条消息预览：头像、会话名、消息摘要、相对时间
- 群聊多人消息自动切换展示发送人，摘要剔除重复前缀
- 点击预览条目直接跳转对应聊天会话
- 「查看全部消息」复用系统原生逻辑，支持小窗、BAL 豁免
- 原生通知卡片折叠隐藏，避免重复占位

## ✅ 音乐实况｜QQ 音乐 / 网易云音乐 / Sait Player

- 胶囊展示播放状态、滚动歌词
- 展开卡片：专辑封面、曲目信息、播放进度、播放 / 暂停、切歌控件
- 歌词取自应用播放通知，切歌自动重置滚动
- 封面切换采用双缓冲淡入

## ✅ 导航实况｜高德地图

- 支持驾车、骑行、步行、公交全模式
- 卡片展示剩余距离、预计时长、到达时间、转向提示与进度条
- 显示目的地名称，支持结束导航、查看路线操作

## ✅ 交互 & 视觉

- 点击胶囊唤起悬浮卡片，无需下拉通知栏；**不抢占焦点，前台应用不会中断**，点击卡片外侧自动收起
- 玻璃质感底、大圆角，跟随系统深色模式
- 多实况卡片自动排布，300ms 缓动过渡，展开收起间距对齐原生系统

## ✅ 兼容 & 安装

- 仅 Flyme 系统可用（依赖 Flyme 实况底层服务）
- **仅在 Flyme 12.5 测试通过**
- LSPosed 作用域：SystemUI、设置、目标 App
- 安装后前往：设置 → 通知与状态栏 → 实况通知，开启对应应用开关

| 应用 | 包名 | 类型 |
|---|---|---|
| 微信 | `com.tencent.mm` | 消息 |
| QQ | `com.tencent.mobileqq` | 消息 |
| TIM | `com.tencent.tim` | 消息 |
| QQ音乐 | `com.tencent.qqmusic` | 音乐 |
| 网易云音乐 | `com.netease.cloudmusic` | 音乐 |
| Sait Player | `com.salt.music` | 音乐 |
| 高德地图 | `com.autonavi.minimap` | 导航 |

> 更新模块后请**同时重启目标 App**：模块只对新启动的进程生效，只重启 SystemUI 时目标 App 里仍是旧代码。

## 🐞 排查

正式包默认不输出任何排查日志。需要现场取证时（root，重启目标进程后生效）：

```bash
adb shell su -c 'setprop debug.flymeark.log true'
```

恢复静默：`setprop debug.flymeark.log false`（手机重启后属性失效，自动回到静默）。
